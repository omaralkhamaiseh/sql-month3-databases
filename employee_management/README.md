# Employee Management System — SQL

## Project Overview
This project is part of my Month 3, Week 1 learning journey toward becoming an AI/DevOps (MLOps) Engineer.

It demonstrates how to create, manage, and analyze employee data using SQLite.

## Features
- Create an employees table with SQL.
- Insert employee records.
- Retrieve and filter employee information.
- Update employee salaries.
- Delete employee records.
- Calculate department salary statistics.
- Use SQL views to generate reports.

## SQL Concepts Practiced
- CREATE TABLE
- INSERT INTO
- SELECT and WHERE
- UPDATE and DELETE
- ORDER BY
- COUNT(), SUM(), and AVG()
- GROUP BY and HAVING
- CREATE VIEW

## Project Files
- `schema.sql` — Defines the employees table.
- `queries.sql` — Contains SQL queries for employee analysis.
- `employee_management.db` — SQLite database containing the project data.

## Tools Used
- SQLite
- DB Browser for SQLite
- Visual Studio Code

## How to Run
1. Open `employee_management.db` using DB Browser for SQLite.
2. Select the **Execute SQL** tab.
3. Run queries from `queries.sql`.
4. Explore the results.

## Learning Outcome
This project helped me practice SQL fundamentals and understand how relational databases store, update, and analyze structured data.
